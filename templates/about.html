About SecureWatch

A portfolio-grade cybersecurity monitoring platform built to demonstrate real-world SOC engineering skills.

What is SecureWatch?

SecureWatch is a lightweight Security Information and Event Management (SIEM) dashboard designed to monitor Linux authentication logs, detect intrusion attempts, and provide actionable threat intelligence to security analysts.

The project was built to showcase practical cybersecurity engineering — from log parsing and anomaly detection to interactive data visualization and role-based access control.

Core Capabilities

The platform parses /var/log/auth.log (and simulated equivalents) to extract SSH failed logins, brute-force patterns, and suspicious IP activity. Every event is stored in a SQLite database and surfaced through a modern dark-themed dashboard.

Threat detection logic assigns severity scores (Low → Critical) based on frequency and behavioral patterns, and automatically generates alerts for security analysts to investigate and resolve.

Tech Stack

Python 3 Flask 3 SQLite SQLAlchemy Chart.js HTML5 / CSS3 JavaScript Werkzeug Flask-WTF (CSRF)

Security Features

All passwords are hashed using PBKDF2-SHA256 via Werkzeug. Sessions are signed with a server-side secret. CSRF tokens protect every form. SQL injection is prevented by SQLAlchemy's parameterized queries. Input validation is enforced on all user-facing fields.
